# Taylor Kinney Fan Connect

An private, static website for Taylor Kinney fans.

## Pages
- `index.html` — home page
- `about.html` — about the fan site
- `gallery.html` — gallery placeholders
- `register.html` — registration/demo form
- `style.css` — shared styling

## Important
The registration form is intentionally a front-end demo. It does not save personal information. To collect submissions, connect the form to a reputable form service or your own secure backend before publishing.

The website should remain clearly labeled as unofficial and should only use images/content you have permission to publish.
